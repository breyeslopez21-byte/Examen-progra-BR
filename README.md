# Examen-progra-BR

Para ejecutar el proyecto, primero descarga el archivo comprimido “Progra2.zip” desde el repositorio. Para hacerlo, entra al archivo y haz clic en “View raw” para iniciar la descarga.
Una vez descargado, descomprime  el archivo.
Luego, abreNetBeans, busca la carpeta descomprimida para abrir el proyecto.
Cuando el proyecto esté cargado, ejecútalo.
Al iniciarse, el programa solicitará en la consola que ingreses un nombre y un correo electrónico. Con estos datos, el sistema registrará al usuario y guardará la información en un archivo de texto (.txt)
creando así un registro dentro del proyecto.
